# Halaskâr — UAV-Based Fire Suppression Platform

> A modular product family that turns UAV/UCAV platforms into active fire suppression
> platforms for early detection and first response to forest fires.

The full write-up is currently available in Turkish only. An English translation is in progress.

## Overview

Halaskâr aims to adapt existing UAV/UCAV platforms for firefighting. It is not a single
device but a set of complementary parts: **pods in different capacities**, **controlled
extinguisher distribution**, **sensors** for early detection, and **targeting systems** so
the first response reaches the right spot.
